# ستوديو آية (Ayah Studio)

<p align="center"><img src="engine/public/logo.png" width="140" alt="آية لمست قلبي"></p>

الأداة بتاخد مقطع صوت أو فيديو لشيخ، وتطلّع منه **ريل 9:16 موشن جرافيك** بهوية قناة «آية لمست قلبي». بعد التسطيب، كل حاجة بتشتغل على جهازك **من غير إنترنت**.

## التسطيب (أمر واحد)

**ويندوز:** افتح PowerShell والصق:
```powershell
irm https://raw.githubusercontent.com/ahmed-mostafa2020/ayah-studio/main/install.ps1 | iex
```

**ماك / لينكس:** افتح Terminal والصق:
```bash
curl -fsSL https://raw.githubusercontent.com/ahmed-mostafa2020/ayah-studio/main/install.sh | bash
```

السكريبت بيعمل الآتي:
- بيسطّب Node.js وPython وffmpeg لو مش موجودين.
- بينزّل الأداة في فولدر `ayah-studio` جوه فولدر المستخدم.
- بينزّل مرة واحدة بس متصفح الرندر وموديل التفريغ (حوالي 3 جيجا).
- بيسألك لو عايز Claude Code كاختيار.

على ويندوز بيعمل كمان اختصار **Ayah Studio** على سطح المكتب.

**التشغيل:** افتح الاختصار، أو شغّل `start.bat` (ويندوز) أو `start.sh` (ماك/لينكس). الداشبورد هيفتح على `http://localhost:4747`.

**الجهاز:** أي جهاز فيه 8 جيجا رام أو أكتر ينفع. كارت الشاشة مش مطلوب، لأن التفريغ والرندر بيشتغلوا على المعالج: مقطع دقيقتين بياخد حوالي 3–5 دقايق تفريغ وحوالي 10 دقايق رندر، وده بيختلف حسب الجهاز.

## خطوات الشغل
1. **المشاريع:** ترفع mp3 أو mp4 أو wav، والتفريغ وكشف الخلفية والآيات بيحصلوا لوحدهم.
2. **التفريغ:** الكلمات المشكوك فيها بالأصفر. تسمعها وتعدّلها، وتشطب التأتأة والحشو.
3. **الآيات والأحاديث:**
   - الآيات بتتطابق أوفلاين مع نص المصحف العثماني.
   - لكل حديث تكتب أو تراجع النص والمصدر، أو تعلّمه «كلام الشيخ».
   - فيه زرار «ابحث بنفسك في الدرر السنية».
   - كل المقاطع دي ممنوع فيها مؤثرات صوت.
4. **الستوري بورد:** تكتب الهوك. كل مشهد ليه 3 وصفات مقترحة (فقاعة تفكير، لافتة، عدّ، وادي دهب، قبر وساعة رملية، دعاء، سجود…)، وتغيّرها بضغطة.
5. **الصور والموافقة:** صورة لكل مشهد، وتوافق أو تطلب تعديل. **مفيش رندر من غير موافقتك.**
6. **الرندر والإخراج:**
   - تقدر تعمل «معاينة أول 20 ثانية» قبل الرندر الكامل.
   - الرندر الكامل بيتعمل على أجزاء، ومعاه المكساج.
   - بيطلّع فولدر فيه: الفيديو، والصورة المصغّرة، و`captions.srt`، و`post.txt` (العنوان والوصف والتعليق المثبّت).

## القواعد المبنية جوه الأداة
**الفاحص** بيمنع الرندر لو فيه أي مخالفة من دول:
- **شرعي:** مفيش أنبياء ولا أي رمز ليهم، ولا رمز لله، ولا تصوير للغيب، ولا عنف. الصحابة من ضهرهم. المصلّي مفيش قدامه أي حاجة. الستات مقفولة افتراضيًا (تتفتح من الإعدادات). ممنوعات PLAYBOOK النشر.
- **واقعية:**
  - الشخصية بتبص على اللي بتعمله.
  - لما تكون عايزة حاجة، جسمها وإيدها وضلها بيتوجهوا عليها، والزاوية محسوبة من مكانها.
  - الحبل بيطلع من الإيد، والضل على الأرض بس.
  - مفيش نص طالع برة شكله.
- **حركة** (`MOTION_RULES`): دخول ease-out، وخروج أسرع، و3 طبقات حركة. مفيش حركة خطية، ومفيش ظهور بالشفافية بس.
- **صوت:** مفيش موسيقى، ولا مؤثرات فوق الآيات أو الأحاديث أو الذكر. لو فيه خلفية صوتية مفيش أي قص. الصوت النهائي بيتوحّد على -14 LUFS.
- **قالب:** أول فريم عمره ما يبقى فاضي، والهوك ثم الكابشن من غير تداخل، واللوجو، والماسكوت (لايك في النص، و«سيب تعليق» و«وانشرها في الخير» في الآخر)، وجملة المشاركة. مفيش اسم الشيخ جوه الفيديو.

## الـ AI اختياري
الأداة كلها شغالة من غير AI. في الأماكن اللي الجودة فيها ممكن تحتاج مساعدة، فيه زرار مكتوب عليه «بيستخدم AI»:
- تخطيط المشاهد
- التحقق من الأحاديث (اقتراح بس، والتأكيد بإيدك)
- تصحيح الكلمات الصفرا
- العنوان والوصف والتعليق المثبّت
- مراجعة الصور

كل زرار بيوريك التوكنز المتوقعة قبل ما يشتغل، وبيديك 4 طرق:

| الطريقة | محتاج إيه | بيتحسب من |
|---|---|---|
| **Claude Code (اشتراكك)** | تسطيب Claude Code وتسجيل دخول مرة | حدود اشتراكك في Claude |
| **انسخ والصق في أي AI** | ولا حاجة | الشات اللي بتلصق فيه (Claude أو ChatGPT أو Gemini) |
| **مفتاح Claude API** | حساب على console.anthropic.com ورصيد | رصيد الـ API (منفصل عن الاشتراك) |
| **Ollama على جهازك** | تسطيب Ollama وموديل | ببلاش (أضعف وأبطأ، ومش بيشوف صور) |

المفتاح (لو استخدمته) بيتحفظ في `config/user.json` بس، مش متغير عام في النظام.

## الأوامر (CLI)
كل حاجة في الداشبورد ليها أمر:
```
node cli/ayah.mjs new <اسم> <ملف>        استيراد
node cli/ayah.mjs prepare <اسم>          تفريغ + خلفية + آيات وأحاديث
node cli/ayah.mjs plan <اسم>             ستوري بورد بالوصفات
node cli/ayah.mjs lint <اسم>             الفاحص
node cli/ayah.mjs stills <اسم>           صور الستوري بورد
node cli/ayah.mjs render <اسم>           الرندر
node cli/ayah.mjs doctor                 يتأكد إن كل حاجة جاهزة أوفلاين
```

## إضافة ستايل أو وصفة أو عنصر
- **وصفة مشهد:** دالة في `pipeline/ayah_pipeline/recipes.py` (التكوين والحركة)، ونمط كلام في `PATTERNS`.
- **عنصر جديد:** رسمة في `engine/src/brand/Extra.tsx` بنفس قواعد الإضاءة، ومقاسه في `geometry.py` علشان الفاحص يحسبه.
- **الهوية:** `engine/src/brand/Brand.tsx` (الألوان، والشخصيات، والماسكوت).

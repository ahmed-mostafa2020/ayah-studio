# ستوديو آية (ayah-studio)

أداة بتاخد مقطع صوت أو فيديو لشيخ، وتطلّع منه ريل 9:16 بهوية قناة «آية لمست قلبي»، وكلها بتشتغل على جهازك **من غير إنترنت** بعد التسطيب.

> الحالة: تحت البناء. المراحل 1–3 خلصت: التفريغ، وكشف الآيات والأحاديث، والستوري بورد بالوصفات، والفاحص، والصور، والداشبورد. الرندر والتسطيب بأمر واحد جايين.

## بتعمل إيه
1. **استيراد** mp3 أو mp4 أو wav.
2. **كشف الخلفية الصوتية:** لو فيه خلفية، مفيش أي قص في الصوت. لو الصوت نضيف، السكتات الطويلة بتتقص.
3. **تفريغ كلمة بكلمة** (faster-whisper large-v3). الكلمات المشكوك فيها بتتعلّم بالأصفر، والتأتأة والحشو بيتشالوا من الكابشن.
4. **كشف الآيات أوفلاين** من نص المصحف العثماني، وكشف الأحاديث والذكر. كلها مناطق ممنوع فيها مؤثرات صوت، ولازم تتأكد قبل الرندر.
5. **ستوري بورد بالوصفات:** كل مشهد معمول من وصفة جاهزة (فقاعة تفكير، لافتة، عدّ، وادي دهب، قبر وساعة رملية، دعاء…)، وتقدر تغيّرها من الداشبورد.
6. **الفاحص:** بيمنع أوتوماتيك أي مخالفة شرعية، أو مخالفة لقواعد الواقعية أو الحركة أو القالب.
7. **صور الستوري بورد:** مفيش رندر فيديو من غير موافقتك على كل مشهد.

## الـ AI اختياري
كل حاجة شغالة من غير AI. فيه زراير اختيارية مكتوب عليها «بيستخدم AI»، وكل زرار بيوريك عدد التوكنز المتوقع قبل ما يشتغل:
- تخطيط المشاهد (حوالي 3 آلاف توكن لمقطع دقيقتين)
- التحقق من الأحاديث (اقتراح بس، والتأكيد بإيدك، ومعاه رابط للبحث بنفسك في الدرر السنية)
- اقتراحات للكلمات المشكوك فيها
- العنوان والوصف والتعليق المثبّت
- مراجعة الصور بموديل بيشوف الصور

## التشغيل (مؤقتًا، لحد ما يجهز سكريبت التسطيب)
```bash
npm install
pip install -r pipeline/requirements.txt
node cli/ayah.mjs doctor
node studio/server.mjs        # بعدها افتح http://localhost:4747
```

الأوامر: `node cli/ayah.mjs` (من غير أي حاجة بيطبع كل الأوامر).
